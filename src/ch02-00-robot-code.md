# Robot Code

You know enough Java to write real robot code now. Everything from here on is a real WPILib robot program, the same kind we run on the robot at competitions.

You won't need a robot for any of it. WPILib can **simulate** a robot on your laptop: it runs your robot code, stands in for the motors and sensors, and shows you what the robot would do. You can write and test robot code anywhere, so by the time you get your hands on the real robot, most of the bugs are already gone.

Over the next several lessons we'll build one robot program a piece at a time: a robot with an arm, an intake and a swerve drivetrain. Drivers can control it, it can drive itself in autonomous, and you can watch it move in the simulator. Nearly every idea from the first part of the book comes back along the way, from `private` fields to lambdas to enums.

After that comes getting ready for the real robot: finding bugs, running code safely on real hardware, and working on the team's code together with Git and GitHub. The last lesson is a project where you build a whole new mechanism yourself.

This book uses **WPILib 2027**. WPILib changed a lot that year, so when you look up help online, check that it's for 2027 or later. Older examples use names that no longer exist.
